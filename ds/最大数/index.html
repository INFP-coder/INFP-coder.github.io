    数据结构 线段树

    最大数

    背景¶

    来源：洛谷 P1198 · 难度：绿 · 日期：2026-11-13

    这是线段树的第二副面孔：把 P3374 的「区间求和」换成「区间最大值」。同时数列是动态增长的——一开始为空，只在末尾插入。

    题意

    维护一个初始为空的数列，两种操作：

    • Q L：输出末尾 \(L\) 个数中的最大值（\(L>0\) 且不超过当前长度）；
    • A n：把 \((n+t)\bmod D\) 插入末尾，其中 \(t\) 是上一次查询的答案（没查过则 \(t=0\)）。

    保证 \(1\le M\le 2\times 10^5\)，\(1\le D\le 2\times 10^9\)，\(n\) 可能为负数。

    思路¶

    1. 插入只发生在末尾：总插入次数不超过 \(M\)，提前开 \(M\) 个位置，空位全部设成 \(-\infty\)（不参与最大值比较）。
    2. 单点赋值 + 区间查询：正是线段树模板，把合并规则从 + 换成 max：
    位置 P3374 求和 P1198 最大值
    叶子赋值 t[id]+=k t[id]=k
    合并 t[id]=t[lc]+t[rc] t[id]=max(t[lc],t[rc])
    查询初值 ans=0 ans=LLONG_MIN
    1. 负数取模：C++ 里负数取模结果仍为负，答案必须落在 \([0,D)\)：
    负数取模
    int x=(input%d+t1)%d;
if(x<0) x+=d;

    易错点（本题亲测踩过的坑）¶

    1. 数组开成 M>>2（\(M\div4\)）而非 M<<2（4 倍空间）→ 越界 RE
    2. build 左儿子写成 (1,mid)，应为 (l,mid) → 区间错乱、编号爆炸 RE
    3. 存值存了原始 input 而不是算好的 x → WA
    4. 每次查询 build(1,1,cnt) 重建整棵树 → \(O(m^2)\) TLE；正确做法是插入时单点 add，永不重建
    5. 输出要换行

    代码实现¶

    P1198 最大数.cpp
    /*
Question: [JSOI2008] 最大数 (线段树维护区间最大值）
Source: P1198
Difficulty: Green
Date: 2026/11/13
做法：线段树
*/
#include<bits/stdc++.h>
using namespace std;

#define int long long
const int M=200010;
int m,d,t1=0,cnt=0;
int t[M<<2];          // 4 倍空间

int lc(int x){return x<<1;}
int rc(int x){return x<<1|1;}

void add(int l,int k,int L,int R,int id){ // 把位置 l 的值改成 k（单点赋值）
    if(L==R){
        t[id]=k;
        return;
    }
    int mid=L+(R-L)/2;
    if(l<=mid) add(l,k,L,mid,lc(id));
    else add(l,k,mid+1,R,rc(id));
    t[id]=max(t[lc(id)],t[rc(id)]);       // 合并：取较大
    return;
}

int query(int l,int r,int L,int R,int id){ // 查询 [l,r] 的最大值
    if(l<=L&&R<=r) return t[id];
    int mid=L+(R-L)/2;
    int ans=LLONG_MIN;
    if(l<=mid) ans=max(query(l,r,L,mid,lc(id)),ans);
    if(r>mid) ans=max(query(l,r,mid+1,R,rc(id)),ans);
    return ans;
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>m>>d;
    for(int i=1;i<M*4;i++) t[i]=LLONG_MIN; // 空位=负无穷，不参与比较
    while(m--){
        string op;
        int input;
        cin>>op>>input;
        if(op=="A"){
            int x=(input%d+t1)%d;         // 防负数取模
            if(x<0) x+=d;
            cnt++;
            add(cnt,x,1,M,1);             // 插入 = 单点赋值
        }
        else if(op=="Q"){
            t1=query(cnt+1-input,cnt,1,M,1); // 末尾 input 个数
            cout<<t1<<endl;
        }
    }
    return 0;
}

    线段树的「作用范围」就体现在这里：只要改「叶子怎么填」和「怎么合并」，同一副骨架就能从求和换成求最大值，查询/修改的递归结构一行都不用动。
